# Provider logos

AWS, Google Cloud, Azure, DigitalOcean, Linode, Oracle, and Amazon SES: Iconify SVG Logos collection, https://github.com/iconify/icon-sets/blob/master/json/logos.json (collection license CC0-1.0). AWS Marketplace uses the AWS brand logo.

OVHcloud, Hetzner, UpCloud, Alibaba Cloud: Simple Icons, https://github.com/simple-icons/simple-icons (CC0-1.0). Original brand colors applied.

Atlantic.Net: site favicon retrieved using Google's favicon service for atlantic.net.

Provider trademarks belong to their respective owners. These assets identify the providers listed in this storefront. Logos are served locally, without runtime requests to third-party icon services.

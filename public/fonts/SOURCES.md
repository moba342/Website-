## Premium typography refresh

Outfit (headings), Plus Jakarta Sans (body/navigation) and JetBrains Mono (prices/technical labels), self-hosted as Latin variable WOFF2 files. Downloaded from the Google Fonts CSS API on 2026-11-27. Font display uses swap. Licenses are included alongside each file and were obtained from the corresponding ofl/outfit, ofl/plusjakartasans and ofl/jetbrainsmono directories in the official google/fonts repository. Heading/body fonts are preloaded; the label face loads on demand.
